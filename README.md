# APKUpdater OSS

[English version](README_EN.md)

**APKUpdater OSS** - приложение с открытым исходным кодом для Android, которое помогает находить, скачивать и устанавливать обновления для приложений вне одного конкретного магазина. Оно собирает информацию из разных источников, группирует результаты по приложениям и дает выбрать подходящий вариант обновления.

Проект ориентирован на смартфоны и сенсорные устройства. Поддержка Android TV намеренно удалена: интерфейс, жесты и сценарии установки рассчитаны на обычное использование на телефоне.

APKUpdater OSS является глубоко переработанным форком оригинального [APKUpdater](https://github.com/rumboalla/apkupdater) от [rumboalla](https://github.com/rumboalla). Приложение устанавливается как `com.apkupdateross`, поэтому может сосуществовать с оригинальным APKUpdater.

## Возможности

- Поиск обновлений для установленных приложений сразу в нескольких источниках.
- Вкладки `Apps`, `Search`, `Updates` и `Settings` с современным интерфейсом на Material 3.
- Группировка одинаковых обновлений из разных источников в одну карточку.
- Выбор источника внутри карточки, если обновление найдено в нескольких местах.
- Метки типа релиза на вкладке Updates: `Stable`, `Beta`, `Alpha`, `Pre-release`.
- Фильтры для скрытия alpha, beta и pre-release версий.
- Кнопка `Обновить всё` для массовой установки доступных обновлений.
- Скачивание APK в `Downloads/APKUpdaterOSS`.
- Установка через обычный Session Installer, Root или Shizuku.
- Фоновая проверка обновлений по расписанию с уведомлениями.
- Автоматическая загрузка и установка в фоне при использовании Root или Shizuku.
- Скрытие отдельных обновлений и приложений, включая управление свайпами.
- Кастомная тема: акцент, фон, карточки и нижняя панель.
- Системная, темная и светлая темы, а также поддержка Material You / Dynamic Color.
- Компактный режим и настройка количества колонок в портретной и альбомной ориентации.
- Бэкап и восстановление настроек.
- Копирование списка приложений и логов.
- Встроенное самообновление с нормальным отображением changelog.

## Источники обновлений

| Источник | Что поддерживается |
| --- | --- |
| GitHub | Релизы, pre-release флаг, пользовательские репозитории, опциональный API-токен |
| GitLab | Релизы, пользовательские репозитории, опциональный API-токен |
| F-Droid / IzzyOnDroid | Настраиваемые репозитории F-Droid и suggested/stable версии |
| Google Play | Поиск и обновления через Aurora GPlayApi с учетом языковых предпочтений устройства |
| RuStore | Поиск, обновления, changelog, прямые ссылки на загрузку |
| APKMirror | Поиск, обновления, страницы загрузки, APKM/split-пакеты и проверка ABI |
| Aptoide | Поиск и обновления из публичного каталога |
| APKPure | Поиск, обновления и базовая фильтрация релизов |
| APKCombo | Экспериментальный источник с вариантами APK и проверкой совместимости |
| Uptodown | Экспериментальный источник с APK/XAPK/APKS, прямой загрузкой и резервным WebView-сценарием |
| AppGallery | Экспериментальный источник Huawei AppGallery с выбором региона |

APKCombo, Uptodown и AppGallery выключены по умолчанию и включаются вручную в `Settings -> Sources`. Некоторые источники зависят от публичных API или HTML-страниц, поэтому могут временно ломаться при изменениях на стороне магазина.

## Настройки

Настройки переработаны по категориям:

- `Источники`: магазины, GitHub/GitLab, F-Droid репозитории и регион AppGallery.
- `Обновления`: фильтры релизов, расписание проверок, уведомления, метрики и скрытые обновления.
- `Установка`: выбор режима установки: обычный, Root или Shizuku.
- `Интерфейс`: тема, кастомные цвета, анимации, свайпы, компактный вид и колонки.
- `Сеть`: глобальный таймаут и отдельный таймаут для Google Play.
- `Данные и логи`: экспорт/импорт настроек, списки приложений и логи.
- `О нас`: версия, GitHub, донаты и информация о проекте.

## Установка

1. Откройте [Releases](https://github.com/EikeiDev/apkupdateross/releases).
2. Скачайте `com.apkupdateross-release.apk`.
3. Установите APK и разрешите установку из неизвестных источников, если Android попросит.

Минимальная версия Android: **7.0 Nougat, API 24**.

## Сборка из исходников

Требуется JDK 17 и Android SDK.

```bash
# Windows
.\gradlew.bat assembleDebug
.\gradlew.bat assembleRelease

# Linux / macOS
./gradlew assembleDebug
./gradlew assembleRelease
```

Готовые APK появляются в:

```text
app/build/outputs/apk/debug/
app/build/outputs/apk/release/
```

Для собственной release-подписи можно указать keystore в `local.properties`. Если конфиг подписи не найден, локальная release-сборка использует debug-подпись.

## Безопасность и ограничения

APKUpdater OSS не является магазином приложений и не хостит APK самостоятельно. Приложение получает данные и файлы из выбранных пользователем источников. Проверяйте источник перед установкой, особенно если обновление найдено не в официальном магазине разработчика.

В обычном режиме Android показывает системное окно установки. Тихая установка доступна только через Root или Shizuku. Приложение не содержит рекламных SDK и аналитики.
