**APKUpdater OSS** помогает находить, скачивать и устанавливать обновления для Android-приложений без привязки к одному магазину. Приложение параллельно опрашивает выбранные источники, группирует одинаковые обновления в единую карточку и позволяет точно контролировать, откуда и какие версии устанавливать.

Проект — глубоко переработанный форк оригинального [APKUpdater](https://github.com/rumboalla/apkupdater) от [rumboalla](https://github.com/rumboalla). Приложение использует идентификатор пакета `com.apkupdateross`, поэтому может быть установлено параллельно с оригинальной версией. Поддерживаются смартфоны, планшеты и устройства Android TV.

## Возможности

### Поиск и контроль обновлений
- **Агрегация из 13 источников** — объединение результатов в одну карточку с переключением источника прямо внутри неё.
- **Приоритет и закрепление источников** — гибкий порядок выбора при совпадении версий и закрепление предпочтительного магазина для конкретного приложения.
- **Фильтрация релизов** — бейджи `Stable`, `Beta`, `Alpha`, `Pre-release` и независимые фильтры скрытия тестовых сборок.
- **Гибкое управление списком** — сортировка, фильтрация по источнику, точечная проверка одного приложения со вкладки `Приложения`, остановка текущей проверки и повторный запуск упавших источников.
- **Скрытие и свайпы** — игнорирование отдельных версий или целых приложений с настраиваемыми жестами свайпа.
- **Умное добавление git-репозиториев** — вставьте ссылку на GitHub, GitLab или Codeberg (или передайте её через системное меню «Поделиться»), и приложение само определит пакет, релизы и подходящий APK.

### Установка и работа с пакетами
- **Три способа установки** — стандартный системный установщик (`Session Installer`), **Root** и **Shizuku** с проверкой доступности прав.
- **Пакетное обновление** — кнопка «Обновить всё» и массовая очередь установки.
- **Локальный установщик** — установка локальных `APK`, `XAPK`, `APKS` и `APKM` из настроек или через системное меню «Открыть с помощью».
- **Резервное копирование APK** — сохранение установленных приложений в папку загрузок (включая упаковку split APK в `.apks`).
- **Понятная диагностика ошибок** — расшифровка конфликтов подписи, нехватки памяти, несовместимости ABI/Android, попыток даунгрейда и повреждённых пакетов.
- **История и самообновление** — журнал проверок и установок, а также встроенное обновление самого APKUpdater OSS с отображением changelog.

### Автоматизация и сеть
- **Фоновые проверки по расписанию** — настраиваемый интервал, время запуска и опция проверки только по Wi-Fi.
- **Тихая автоустановка** — автоматическая загрузка и установка обновлений в фоне через Root или Shizuku (с опцией «только по Wi-Fi»).
- **Тонкие уведомления** — раздельные переключатели для доступных обновлений, успешных автоустановок, ошибок и проверок без обновлений.
- **Прокси и таймауты** — глобальный HTTP / SOCKS5 прокси (с авторизацией и тестом подключения), настройка общего таймаута источников и отдельного таймаута Google Play.

### Интерфейс и персонализация
- **Material 3 и динамические цвета** — системная, тёмная, светлая темы, поддержка Material You и редактор собственной цветовой схемы (акцент, фон, карточки, навигация).
- **Адаптивная сетка** — компактный режим и настройка числа колонок для портретной и альбомной ориентации.
- **Язык в приложении** — переключение между системным, русским и английским языками без смены языка Android.
- **Управление данными** — выбор папки сохранения, очистка кеша загрузок и кеша магазинов, экспорт/импорт настроек (без утечки токенов и учётных данных), копирование списка приложений и логов.

## Источники обновлений

### Репозитории кода

| Источник | По умолчанию | Возможности |
| --- | :---: | --- |
| **GitHub** | Вкл | Релизы, `pre-release`, автоопределение по URL, пользовательские репозитории, опциональный API-токен |
| **GitLab** | Вкл | Релизы, автоопределение по URL, пользовательские репозитории, опциональный API-токен |
| **Codeberg** | Вкл | Релизы, автоопределение по URL, пользовательские репозитории, опциональный API-токен |

### Магазины приложений

| Источник | По умолчанию | Возможности |
| --- | :---: | --- |
| **Google Play** | Вкл | Поиск и обновления через Aurora GPlayApi, локализация устройства, автообновление сессии при HTTP 429 |
| **RuStore** | Вкл | Поиск, обновления, changelog, прямые загрузки и сброс кеша 404 |
| **F-Droid / IzzyOnDroid** | Вкл | Встроенные и пользовательские F-Droid репозитории, проверка рекомендованных/стабильных версий |
| **APKPure** | Вкл | Поиск, обновления и базовая фильтрация релизов |
| **Aptoide** | Вкл | Поиск и обновления из публичного каталога |
| **APKMirror** | Выкл | Поиск, обновления, `APKM` / split-пакеты, проверка ABI и интерактивная проверка Cloudflare |
| **APK20** | Выкл | Поиск, варианты APK и проверка совместимости |
| **Uptodown** | Выкл | Поиск, `APK` / `XAPK` / `APKS`, прямая загрузка и резервный WebView-сценарий |
| **AppGallery (Huawei)** | Выкл | Поиск и обновления с выбором любого региона (автоопределение или страна по коду ISO) |
| **Galaxy Store (Samsung)** | Выкл | Поиск и обновления для международного каталога и каталога Китая (CN) |

> [!NOTE]
> Источники со статусом **Выкл** можно в любой момент включить в **Настройки → Источники**. Сторонние магазины зависят от публичных API или веб-страниц и могут временно ограничивать запросы при изменениях на их стороне.

## Установка

1. Перейдите в раздел **[Releases](https://github.com/EikeiDev/apkupdateross/releases/latest)**.
2. Скачайте файл `com.apkupdateross-release.apk`.
3. Откройте APK и разрешите установку из неизвестных источников при запросе системы.

**Требования:** Android **7.0 Nougat (API 24)** или новее.

> [!IMPORTANT]
> Debug- и Release-сборки подписаны разными ключами, поэтому Android не позволяет установить release APK поверх debug-сборки. Для перехода экспортируйте настройки, удалите debug-версию, установите release APK и импортируйте настройки обратно.

## Сборка из исходников

Для сборки потребуются **JDK 17** и **Android SDK (compileSdk 35)**.

```bash
# Windows
.\gradlew.bat testDebugUnitTest assembleDebug
.\gradlew.bat assembleRelease

# Linux / macOS
./gradlew testDebugUnitTest assembleDebug
./gradlew assembleRelease
```

Готовые APK сохраняются в:

```text
app/build/outputs/apk/debug/com.apkupdateross-debug.apk
app/build/outputs/apk/release/com.apkupdateross-release.apk
```

<details>
<summary><strong>Настройка подписи для release-сборки (local.properties)</strong></summary>

Для задачи `assembleRelease` требуется настроить собственный keystore в файле `local.properties` в корне проекта:

```properties
keystore.file=release.jks
keystore.password=your_store_password
keystore.keyalias=your_key_alias
keystore.keypassword=your_key_password
```

Без этих параметров `assembleRelease` завершится ошибкой, а `assembleDebug` соберётся со стандартным debug-ключом.

</details>

## Безопасность и приватность

- **Без рекламы и телеметрии** — в приложении отсутствуют рекламные SDK, трекеры и аналитика.
- **Прямая работа с источниками** — APKUpdater OSS не является магазином и не хранит APK на своих серверах; все метаданные и файлы загружаются напрямую из выбранных вами источников.
- **Защита настроек при экспорте** — токены доступа (GitHub, GitLab, Codeberg), логин/пароль прокси, сессия Google Play и временные кеши автоматически исключаются из файла экспорта.
- **Контроль установки** — в обычном режиме Android всегда запрашивает подтверждение перед установкой; автоматическая установка без подтверждения работает только при явном выборе Root или Shizuku.

> [!TIP]
> Всегда проверяйте выбранный источник в карточке перед установкой, особенно если обновление найдено в стороннем каталоге, а не в официальном репозитории разработчика.
